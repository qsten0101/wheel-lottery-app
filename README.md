# 轉盤抽抽樂：後台倍率版

這是一個完全前端的手機轉盤抽獎工具，可直接上傳到 GitHub Pages 使用。

## 新增功能

- 右上角「後台倍率」按鈕。
- 預設管理密碼：`admin123`。
- 每個獎項可設定倍率。
- 倍率 `0` 代表不會被抽中。
- 倍率越高，中獎權重越高。
- 主畫面會顯示每個項目的倍率與預估百分比。

## 抽獎邏輯

系統使用加權亂數。例：

- A 倍率 1
- B 倍率 3

則 B 的抽中權重約為 A 的 3 倍。

## 修改管理密碼

打開 `app.js`，找到：

```javascript
const ADMIN_PASSWORD = "admin123";
```

改成你要的密碼即可。

注意：這是純前端本機簡易保護，密碼仍然在程式碼中，不適合保護真正機密資料。
